# Nursing Audit Hub delivery outcomes

- [x] Design system and shell: light/dark themes, responsive sidebar/mobile navigation, global ward filter, accessible labels/focus states, formal navy/teal palette, serif headings, simulation footer note.
- [x] Supabase integration: use configured URL and anon key; read seeded data; document migrations, seed data, storage buckets and role model; preserve RLS and never expose service-role credentials.
- [x] Overview: filter-responsive KPI tiles, 2026 trend chart with 90% target, compliance by standard, 10×7 ward heatmap with legend/detail interaction, attention/upcoming lists and six-stage audit cycle.
- [x] Planned audits: Q1–Q4 progress, quarter/status filters, audit table with coloured score bands and simulation add affordance.
- [x] Unplanned audits: trigger breakdown, request form and log table.
- [x] Pending audits: ageing/waiting charts, days-waiting sort, owners and reminder toast/logging.
- [x] Action plans: visible corrective-action table with computed band/status presentation.
- [x] Tools, reports and standards: tool cards and links, report search/status filters, reference and status-history drawers, upload affordance and standards library.
- [x] Quality initiatives, training and liaisons: PDSA cards, resource filters/links, liaison KPIs and searchable table.
- [x] Certificates: two five-question courses, Supabase server-side scoring, attempts/certificate number generation, A4 landscape PDF and public verification lookup.
- [ ] Validation and delivery: live auth role assignment, durable create/edit/upload flows for every admin affordance, storage PDF persistence, README is complete, build/check passes, checkpoint is saved. Current preview is intentionally safe simulation UI where these integrations are not yet wired.
